# Русский вокал в Suno

Короткий раздел о том, что отличается, когда текст на русском. Всё остальное (структура, теги, поле Style) такое же, как в английской части.

## Поле Style

- Style всегда пишется по-английски: модель читает дескрипторы, а не язык песни. Язык задаётся отдельно: `Russian-language vocals, clear diction`. `brief.py --lang ru` добавляет эти два дескриптора сам.
- Полезные уточнения для русского вокала: `clear diction` (иначе глотает окончания), `vocal up front` (голос выше в миксе, слова разборчивее), `unhurried phrasing` для баллад.
- Жанры с русской спецификой в `references/genres.json`: `russian rock`, `russian chanson`, `russian pop`. Это редакционные заготовки, не измерения: правьте.

## Слоги

- Один гласный = один слог: `се-вер-ный` (3), `о-сты-ва-ет` (4). Предлоги `в`, `к`, `с` без гласной = 0 слогов; при пении они прилипают к следующему слову, так что счёт честный.
- Русские слова длиннее английских, поэтому бюджет строки выше: куплет 8–11 слогов, припев 6–9, хук 5–8. `lyric_meter.py` считает точно (по гласным); проверяйте только разброс внутри секции.
- Ударение скрипт не знает. Если строки равны по слогам, но «не ложатся», скорее всего, разъехались ударения: прочитайте вслух под счёт на 4.

## Рифма

- Скрипт сравнивает окончания слов: `окно / давно` → полная (`A A`), `дорога / нога` → полная, `двери / говори` → полная. Строчная буква в схеме (`ABAb`) означает совпадение только последних двух букв: неточная рифма.
- Мужская (ударение на последний слог: `горит / говорит`) и женская (`утра / вчера` нет, это мужская; `дорога / тревога` женская) рифмы скрипт не различает. В припеве мужская рифма звучит твёрже, в куплете можно чередовать.
- Не рифмуйте глагол с глаголом четыре строки подряд (`-ить / -ать`): модель поёт это ровно, но слушатель слышит заготовку.

## Буква ё и дикция

- Пишите `ё`, где она есть: `ещё`, `моём`, `прочтённые`. Без точек модель иногда поёт `е`.
- Избегайте стечений согласных на длинных нотах в припеве: `-ств`, `-стр`, `-здр`. Открытые гласные на концах строк (`-а`, `-о`, `-е`, `-и`) тянутся лучше.
- Дефис в составных словах (`о ком-то`) модель читает нормально; тире между частями строки (`—`) тоже, но не ставьте его в конце строки.

## Штампы, которые надо вырезать

`неоновый свет` · `город спит` · `сквозь года` · `на краю земли` · `вопреки всему` · `навсегда с тобой` · `в сердце огонь` · `дождь за окном` (если он не делает чего-то конкретного) · `мы будем вместе` · `в этом мире`

Заменяйте предметом, который можно сфотографировать: не «дождь за окном», а «чай на столе остывает давно».

## Пример

`examples/lyrics/severny-veter.ru.txt`: куплеты по 10 слогов, припев по 8, схемы `AABB` в куплете и `ABAb` в припеве (последняя строка «обо мне» рифмуется с «окне» неточно по скрипту, по слуху полная). Отчёт: `examples/outputs/severny-veter.meter.txt`. Стиль: `examples/style/severny-veter.ru.txt`.
