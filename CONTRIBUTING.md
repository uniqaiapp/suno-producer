# Contributing

Thanks for helping. Small, specific pull requests land fastest.

## What is welcome

- A genre block for `references/genres.json` with the song you tested it on (tempo range, keys, instruments, production words, default vocal, structure). Say which Suno version.
- A tag that works and is missing from `references/section-tags.md` and `KNOWN_TAGS` in `scripts/suno_lint.py`.
- A troubleshooting row (`references/troubleshooting.md`): symptom, cause, the one change that fixed it.
- Syllable or rhyme cases the heuristics get wrong, as a failing test in `tests/test_meter.py` plus the fix.
- Russian-language findings for `references/russian-vocals.md`.

Not welcome: copyrighted lyrics (even as "test data"), artist names in prompts, dependencies of any kind, invented numbers.

## Local checks

```bash
python3 tests/run.py          # unit tests + adapters + byte-for-byte example reproduction
python3 examples/regen.py     # after changing a script or example input; review the diff
```

Tests must stay under ten seconds and need no network. Python 3.9 is the floor (no `match`, no `X | Y` type syntax).

## Pull request checklist

- `python3 tests/run.py` is green.
- If you changed a script, `python3 examples/regen.py` was run and the output diff is explained in the PR.
- Any new number in a README or reference is produced by a script here on a file here, or cites a dated source.
- No personal names, no secrets, no copyrighted lyrics.
- Version bump (`SKILL.md` metadata, `.claude-plugin/plugin.json`, `CHANGELOG.md`) only when the maintainers ask.

## Assets

`assets/banner.svg`, `assets/banner-light.svg`, `assets/demo.svg` and `assets/social-preview.png` are generated by the shared uniqaiapp design kit (Node built-ins plus `sharp` for the PNG, maintainer-only). `demo.txt` at the repo root is the terminal transcript the demo is rendered from; it must be real script output. Do not edit the SVGs by hand; open an issue and a maintainer regenerates them.

## Deviations from org conventions

- `README.md` follows the newer `README.template.md` layout (badge row, feature grid, Quickstart, FAQ) rather than the older section list in `CONVENTIONS.md` §4; the install block, "Limits and honesty", "Related" and the footer wording from the conventions are kept.
- `.gitignore` lists the usual dependency directories although there are none; the forbidden-string test exempts that one file.
- The CC BY 4.0 section of `LICENSE` links to the legal code instead of embedding its full text, to keep the repo small.
